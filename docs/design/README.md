# Design-Vorbild

`vorbild-dashboard.jpg` ist der Dashboard-Entwurf, an dem sich Plan4JU orientiert (André, 13.11.2026).
Die Namen darin sind erfunden.

Was übernommen wird:
- Kopf: große Uhrzeit, Datum, Begrüßung der Familie, Hinweis auf die Tageszeit („Morgens · gleich geht's los“)
- Karte „Als Nächstes · in 33 Minuten“ mit Person (farbiger Avatar mit Initiale), Zeit und Ort, daneben „Danach“
- „Heute zu Hause“: Zeitstrahl 6–22 Uhr, eine Zeile je Person, Jetzt-Linie
- „Diese Woche“: sieben Tageskarten Mo–So, heute hervorgehoben, „+n weitere“
- Seitenleiste: Essen heute, Schule heute, Sterne/Belohnungen
- Ruhige Flächen, weiche Karten, je Person eine feste Farbe

Für Release 0.1 gilt nur der Rahmen: Kopf, „Diese Woche“ mit Aufgaben und Geburtstagen, Personenfarben.
Kacheln späterer Module (Essen, Schule, Sterne, Wetter, Zeitstrahl mit Terminen) erscheinen als „kommt bald“.
Oberfläche auf Deutsch, mobil zuerst: auf dem iPhone werden die Kacheln untereinander gestapelt.

Stand 0.1.6: „Als Nächstes“/„Danach“, „Heute zu Hause“ (Zeitstrahl 6–22 Uhr mit Jetzt-Linie, Termine und Routinen) und „Diese Woche“ sind gebaut; Essen, Schule, Sterne bleiben „kommt bald“. Wetter und Tageszeit-Bilder fehlen noch.
